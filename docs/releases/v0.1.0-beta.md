The first public beta of **celmic**: use your phone as your computer's microphone. Open source, no ads, low latency.

## What's in it

- **Your phone becomes a real microphone on Windows.** Discord, Zoom, OBS and every other app see a **Celmic Microphone**: no VB-CABLE, no test mode. celmic serves a USB Audio Class 2.0 microphone over USB/IP and [usbip-win2](https://github.com/vadimgrn/usbip-win2) (open source, signed by Microsoft) attaches it to Windows' own USB audio driver.
- **Low latency.** Audio never touches JavaScript: native capture on the phone, 10 ms UDP packets, and a Rust jitter buffer that absorbs Wi-Fi jitter and the clock drift between phone and PC.
- **Pair in seconds.** Scan the QR code, or pick your PC from the list and type the 6-digit code. Nobody else on the network can send audio to it.
- **Voice or raw.** Noise suppression, echo cancellation and gain control for calls, or the unprocessed mic for music.
- **A new look.** Desktop and phone share one design: the state of the stream is the colour of the stripe (vermilion on air, amber connected but silent, cobalt waiting), and the phone shows a giant mute key while you stream.

## Install

**Windows 10/11 (64-bit):** download `Celmic_0.1.0-beta_x64-setup.exe` and run it. The installer is not code-signed yet, so Windows SmartScreen may warn you: choose **More info → Run anyway**. In celmic, open **Output → Set up Celmic Microphone**; Windows asks for permission once to install usbip-win2. Then pick **Celmic Microphone** as the input in your apps.

**Android 7.0+:** download `celmic-v0.1.0-beta-android.apk` on the phone and open it; Android asks you to allow installs from your browser or file manager. Both devices must be on the same Wi-Fi.

The APK is signed with celmic's release key. Its certificate's SHA-256 fingerprint is:

## Known limitations

- This is a beta: expect rough edges, and please report them in [Issues](https://github.com/blackfoxsoftware/celmic/issues).
- The pairing code changes every time the desktop app starts, so the phone has to pair again after a restart.
- No iPhone, macOS or Linux builds in this release yet; they can be built from source (see the README).
